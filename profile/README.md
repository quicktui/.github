# QuickTUI

**Agents on your computer, live on your phone.**

QuickTUI is a self-hosted remote terminal for iPhone, iPad and Android. Attach to tmux or [Herdr](https://herdr.dev) on your own computer and run Claude Code, Codex, OpenCode, Grok or any other CLI agent from anywhere. Connections are direct and end-to-end encrypted.

- Website: [quicktui.ai](https://quicktui.ai/?ref=github)
- iPhone / iPad: [App Store](https://apps.apple.com/app/quicktui/id6761338192)
- Android: [quicktui.ai/android](https://quicktui.ai/android/?ref=github)

## Get started

Install QuickTUI Server on the computer that runs your agents:

```sh
# macOS / Linux
curl -fsSL https://quicktui.ai/q.sh | sh
```

```powershell
# Windows
irm https://quicktui.ai/q.ps1 | iex
```

Then pair your phone with the QR code the installer shows.
